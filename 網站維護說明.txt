三、簡單維護方式
1. 取得所屬 GitHub 儲存庫的編輯權限。
2. 在 GitHub 上開啟網站檔案，修改內容、連結或圖片。
3. 儲存提交（Commit）；由 GitHub Pages 完成部署。
4. 發布後測試桌機/手機與六大功能連結。

四、如需「登入後直接修改資料」
必須額外建置身分驗證與資料編輯/發布流程，可考慮整合 GitHub 授權的內容管理系統（CMS）及受控的後端驗證服務，不能只在純 HTML 網頁加登入框。
注意：請先確認機關資訊安全規範、帳號權限、存取紀錄與審核流程。
